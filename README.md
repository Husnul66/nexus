# Nexus

Nexus, küçük işletmeler ve KOBİ'ler için kanıta dayalı yazılım fırsatı keşfini desteklemeyi amaçlayan dahili kişisel araç projesidir.

Bu depo şu an planlama ve gereksinim aşamasındadır; uygulama kodu henüz yoktur. Kesin mimari, teknoloji yığını ve otomasyon kapsamı gereksinim incelemesinden sonra kararlaştırılacaktır.
